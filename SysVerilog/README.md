# SystemVerilog

SystemVerilog design and verification projects.

## SVDA_21_10 — VeriRISC CPU

A reduced instruction set processor implemented in SystemVerilog, with full verification infrastructure:

- RTL modules: ALU, controller, counter, register, memory, CPU top
- Testbenches with assertions and functional coverage
- Adder modules (combinational and parameterized N-bit)
- Semaphore-based synchronization (lab22)

See [SVDA_21_10/VeriRISC/](SVDA_21_10/VeriRISC/) for the CPU implementation.
