# Verilog

Digital design projects implemented in Verilog HDL.

| Project | Description |
|---------|-------------|
| [DSP/](DSP/) | DSP IP block library (FFT, FIR, IIR, CORDIC, NCO, decimator, interpolator, etc.) + guitar amplifier FPGA application |
| [RISC-V/](RISC-V/) | RV64IMAFD multi-cycle processor — 156 instructions, IEEE 754 FPU, 4-level test infrastructure |
| [GPS/](GPS/) | GPS L1 C/A code generator |
| [HASH/](HASH/) | MD5 hash function implementation |
| [Misc/](Misc/) | Basic digital building blocks (frequency divider, RS latch, D flip-flop) |
| [VLA_28_0/](VLA_28_0/) | VeriRISC — reduced instruction set processor |
